# eli5-visual-explainer v1 — むずかしい話を、大きな図で

お題を1つ受け取り、**その分野を1ミリも知らない人**が3分で「だいたい分かった」と言える
**1枚のHTML**を作る。文字ではなく**図**が主役。

## ELI5とは

**Explain Like I'm 5**（5歳児にも分かるように説明して）の略。
Anthropicが運営する**コミュニティ・プラグイン置き場**で配られている考え方で、中身はとても短く
「大きな絵と少ない文字のHTMLで」としか書かれていない。
（作った本人は「公式プラグインにするかは検討中」と述べている＝**公式プラグインではない**）

つまり**見た目は、そのとき有効なデザイン指示に丸ごと引きずられる**。
このSkillは、そこに**決まった見た目**と**関係図の描き方**と**機械の検問**を足したもの。

---

## 1. 見た目の4つの決まり

**この4つがこのSkillの正本。**（判断を求めるボタンは置かない。読んで終わる資料なので）

### 決まり1 図解ファースト

結論・構造・流れは、**図／表／カードで先に見せる**。文章はその補足にまわす。
「読めば分かる」は作り手の言い分で、読み手には届かない。
人が資料で消耗するのは「内容が難しい」からではなく「渡され方が悪い」から。

### 決まり2 1画面1論点

**スクロールしないと分からない図を作らない。**細かい話は `<details>` の開閉に畳む。
1つのセクションに論点を2つ以上入れない（入るなら、それはセクションが2つに割れていない合図）。

### 決まり3 文字壁は機械で検問

連続文字量・図の数・スマホ対応を、**目で見る前にスクリプトで判定してから出す**。
人の目は疲れるし、作った本人の目はいちばん甘い。関門は機械に置く（→ 手順4）。

### 決まり4 スマホでも成立する

- `<meta name="viewport">` を必ず入れる
- 横スクロールしていいのは**表や図の中だけ**（`overflow-x:auto` の囲み）。ページ全体を横に振らせない
- 1カラムで崩れないこと

### 色と文字

`reference/design-tokens.css` の `:root` を、**HTMLの `<style>` の先頭にそのままコピーする**。
外部ファイルを読み込む形にしない（1枚で完結させ、10年後もオフラインで開けるように）。

**色は発明しない。**このトークンの外の色に意味を持たせない（規律 > 装飾）。

## 2. 作り方（4手）

### 手順1 お題を「知らない人のつまずき」に割る

いきなり書き始めない。まず**3〜5個の問い**に割る。
「これは何？」「なぜ要る？」「どう動く？」「何がうれしい？」「気をつけることは？」

**1つの問い＝1つのセクション＝1つの図。**

### 手順2 たとえ話を1本だけ通す

**全体を通して同じたとえで押し切る**（途中で乗り換えるのが、いちばん混乱する）。
技術用語は使わない。どうしても要るときは**先に平易な言い換えを書き、括弧で用語を添える**。

### 手順3 文字を図に変える

各セクションは**図が主役・文が補足**。ただし「図」の意味を取り違えないこと。

> **箱を並べただけのものは、図ではない。**
> カードを3枚置く・アイコンを添える・枠線を付ける——これらは**装飾であって図解ではない**。
> 図解とは、**要素どうしの関係を、線と矢印で目に見せること**を言う。

**まず関係を疑う。**セクションの中身が次のどれかなら、**関係図を描く**（他の形で代用しない）。

- 順番がある（AのあとにB）／ものが移動する（AからBへ渡す）
- 誰かが誰かに頼む・返す／片方向か両方向か区別がある
- 中に入っている・外にある（囲いで示す）

#### 関係図の描き方（矢印の作法）

**必ず自分でSVGを描く。**アイコンを並べただけでは図にならない。

| 決まり | 中身 |
|---|---|
| **矢印には必ずラベル** | 矢印の上か横に「何が流れるのか」を短く書く。**ラベルの無い矢印は、線を引いただけで情報がゼロ** |
| **向きを描き分ける** | 片方向＝矢じり1つ／両方向＝矢じり2つ／「ときどき」「自動で」＝破線。向きの違いが、いちばん伝わる情報 |
| **囲いで「どこにあるか」を示す** | 角丸の枠でくくり、枠自体にラベルを付ける（例:「あなたのパソコンの中」） |
| **登場人物は5つまで** | 6つ以上になったら、そのセクションが2つに割れていない合図 |
| **図の下にひとこと** | 図のすぐ下に、その図でいちばん言いたいことを1行だけ置く |

#### 関係が無いときに使う形

並列・比較・数量には、関係図を無理に使わない。

- **比較の2枚並べ**（前と後・AとB）／**番号カード**（並列の要素）／**大きい数字1つ＋ひとこと**

**1セクションの地の文は3行まで。**それ以上書きたくなったら、それは図に割れていない合図。

### 手順4 検問を通してから開く

```bash
python scripts/check_layout.py --reference "<作ったHTMLのフルパス>"
```

`--reference` を付ける（読んで終わる資料なので「押せる部品」の条件だけ免除される）。
**合格してから**ブラウザで開く。

> **この検問は「文字壁かどうか」しか見ていない。**箱もカードも「図」として数えるので、
> **矢印が1本も無くても合格が出る。**関係が描けているかは、手順3のチェックで自分が見る。

道具そのものが壊れていないかは `python scripts/check_layout.py --selftest` で確かめられる。

## 3. 図を、そのまま動画で動かす場合（★動画にするなら必須）

`article-motion-slides-v2`（記事を動くスライド動画にするSkill）と組み合わせると、
**ここで描いた図が、そのまま動画のスライドとして動く**——箱が1つずつ現れ、矢印が這う。

**そのときは、図を次の形で描く。**守っていれば、動画側は**機械が運ぶだけ**で済む。
守っていないと、動画側で人が図を描き直すことになり、**同じ図が2枚できてズレる**。

```html
<svg data-fig="q5" viewBox="0 0 760 340" role="img" aria-label="…">
  <defs>…</defs>
  <g data-part="1" data-cue="1"><!-- 左の箱 -->…</g>
  <g data-part="2" data-cue="2"><!-- 右の箱 -->…</g>
  <g data-part="3" data-cue="3" data-arrow="1"><!-- 矢印① -->…</g>
</svg>
```

| 決まり | 書き方 | なぜ |
|---|---|---|
| 図に名前を付ける | `data-fig="q1"` | 動画側からこの名前で呼ぶ。無いと機械が運べない |
| 部品を順番でくくる | `<g data-part="1">` | この順に出てくる。同じ番号は同時に出る |
| 何文目に合わせるか | `data-cue="3"` | 「つなぐ道を4本」と読み上げる文で道が出る、という合わせ方ができる。省略すると機械が均等に割り振る |
| 這わせる矢印を印す | `data-arrow="1"` | 線が伸びる動きになる。**帯（ピル）が本体で線が短い図には付けない**（数pxしか這わず、見えない） |
| **文字は13px以上** | `font-size="13"` 以上 | 画面に置くと約2倍になる。13px未満は動画で読めない（機械が止める） |

**部品の切れ目は、要素の番号ではなく「言葉」で決める。**
「この文字が出てくる要素から次の部品」と書けば、目で読めて、ズレたら分かる。
番号で切ると、1つズレただけで別の部品に混ざる（実際に混ざり、右の箱と1本目の矢印が同じ部品になった）。

**枚数の上限**：動画にするなら、図はショート1〜2枚／ミドル4〜6枚／講義6〜8枚まで。
これを超えると、必ずどれかが動画に入らない。

## 4. 保存先

好きな場所でよい。ファイル名は `eli5_<お題>.html` のように、後から探せる形にする。
チャットの返事にも**フォルダ名とファイル名を書く**（読み手に探させない）。

## 5. 出す前のチェック

- ☐ 図／表／カードが**セクション数と同じだけ**ある（文だけのセクションが無い）
- ☐ **ラベル付きの矢印が1本以上ある**（0本なら、それは図解ではなく装飾。手順3に戻る）
- ☐ **自分で描いたSVGの関係図が1枚以上ある**
- ☐ 矢印の**向き**が中身と合っている（片方向／両方向／破線を描き分けた）
- ☐ たとえ話が**最初から最後まで同じ1本**
- ☐ 技術用語が**言い換えなしで出ていない**
- ☐ 地の文が3行を超えるブロックが無い
- ☐ `scripts/check_layout.py --reference` に合格した
- ☐ スマホで開いても崩れない（viewport／1カラム／横スクロールは表や図の中だけ）
- ☐ 動画にするなら、`data-fig` と `data-part` を付け、文字は13px以上にした
