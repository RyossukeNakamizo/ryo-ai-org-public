# eli5-visual-explainer v1 — むずかしい話を、大きな図で

**「これ、まったく知らない人に説明して」**とAIに頼むと、大きな図と少ない文字の
**1枚のHTML**が返ってきます。読むのに3分。

## 何が違うのか

ELI5（Explain Like I'm 5＝5歳児にも分かるように説明して）は、
Anthropicが運営する**コミュニティ・プラグイン置き場**で配られている考え方です。
（公式プラグインではありません。作った本人が「公式にするかは検討中」と述べています）
ただし中身はとても短く、「大きな絵と少ない文字のHTMLで」としか書かれていません。

つまり**見た目は、そのときのAIの気分しだいで毎回変わります**。

このSkillが足したのは3つです。

1. **決まった見た目**（色・文字・余白が毎回そろう）
2. **関係図の描き方**（矢印にラベルを付ける・向きを描き分ける・囲いで場所を示す）
3. **機械の検問**（文字だらけになっていないかを、出す前にスクリプトが調べる）

## 「図」と「装飾」は別物です

このSkillがいちばんこだわっているのはここです。

> カードを3枚置く・アイコンを添える・枠線を付ける——これは**装飾**であって図解ではありません。
> **図解とは、要素どうしの関係を、線と矢印で目に見せること**を言います。

だから「AがBに渡して、Bが作る」という話が出てきたら、
**箱と矢印の関係図を必ず描きます**。矢印には「何が流れるのか」を書きます。

## 使い方

1. このフォルダを、Skillを置く場所に**フォルダごと**入れる（下の「置き場所」を参照）
2. AIに頼む——「これを図解で噛み砕いて」「5歳児にも分かるように説明して」
3. できたHTMLをブラウザで開く

お題は何でもかまいません。長い記事、むずかしい仕様、自分のメモ。

## 置き場所

Skillの機能があるAIツール（Claude Codeなど）をお使いなら、
`eli5-visual-explainer-v1` の**フォルダごと**、Skillを置く場所に入れてください。
Claude Codeなら `~/.claude/skills/`（Windowsなら `C:\Users\あなたの名前\.claude\skills\`）です。

**場所が分からなければ、AIに聞いてください。**
「Skillはどのフォルダに置けば読み込まれますか」と聞けば教えてくれます。
環境によって違うので、聞くのがいちばん確実です。

**いきなり普段のSkillsフォルダに入れるのが不安な方**は、一時的に別の場所へフォルダごと置いて、
AIと対話しながら必要な要素を足していく進め方でも大丈夫です。
**このSkillはあくまで「キッカケ」**です。自分の環境に合わせ込んで使うのが大前提だと思っています。

## 必要なもの

- **Python 3.10以上**（検問スクリプトを動かすため。図解を作るだけなら無くても動きます）
- それだけです。インストールするライブラリはありません（標準の機能だけで動きます）

## 検問（出す前に1回だけ）

```bash
python scripts/check_layout.py --reference "<作ったHTMLのフルパス>"
```

見ているのは4つです。

1. 文章が長く続きすぎていないか
2. 図・表・カードがいくつあるか
3. スマホで開いても崩れないか
4. 1つのカタマリに詰め込みすぎていないか

**ただし、この検問は「文字壁かどうか」しか見ていません。**
箱もカードも「図」として数えるので、**矢印が1本も無くても合格が出ます**。
関係がちゃんと描けているかは、最後にあなたの目で見てください。

道具そのものが壊れていないかは、こうして確かめられます。

```bash
python scripts/check_layout.py --selftest
```

## 色を自分のものにしたいとき

`reference/design-tokens.css` の `:root` にある色の値を書き換えるだけです。
既定はデジタル庁のデザインガイドに準拠した白基調（公共データ利用規約 PDL1.0）。

**色は発明しないでください。**このトークンの外の色に意味を持たせないのが原則です
（規律があるほうが、毎回そろいます）。

## 作った図を、そのまま動画にできます

`article-motion-slides-v2`（記事を動くスライド動画にするSkill）と組み合わせると、
**ここで描いた図が、そのまま動画のスライドとして動きます**——箱が1つずつ現れ、矢印が這います。

読み物の図と動画の図が**同じ図**になるので、2回描く手間もズレも起きません。

そのときは、図に名札を付けて描きます（`SKILL.md` の第3章に書いてあります）。

```html
<g data-part="1" data-cue="1">…左の箱…</g>
<g data-part="2" data-cue="2">…右の箱…</g>
```

`data-cue` は「何文目の読み上げに合わせて出すか」です。
「つなぐ道を4本つくりました」と言った瞬間に道が出る、という合わせ方ができます。
